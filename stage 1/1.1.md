# Prompt 1.1 输出：10 个垂直微观痛点场景

基于已确定的 MVP 定位（"前台温柔科普 + 后台硬核整理 + 严守合规底线"），以下从真实临床摩擦中切出 10 个可独立成功能模块、又相互互补的微观场景。每个场景都设计为可在 36 小时内用 Streamlit + Minimax + MCP + RAG 组合快速 demo。

---

## 场景一：家族病史"白话文 → HPO 术语"实时翻译器

### Problem Statement (痛点界定)
**目标用户**：罕见病患儿的父母、慢病家族聚集人群。
**核心摩擦**：家属走进诊室带着 5 年攒下的零散记忆，用大量口语化表达倒苦水（"我外甥两岁还不会叫爸妈"、"我老公走路老无缘无故摔跤"）。医生只能凭借速记能力在 15 分钟门诊里强行理解，频繁遗漏关键阴性/阳性表型与时间线。

### 为什么传统方案失效
- 关键词匹配（TF-IDF/正则）无法处理否定句、时态、亲属关系与置信度（如"我大舅**没有**这毛病，但我表妹**好像有点**..."）。
- 没有标准化的 HPO 映射能力，门诊医生只能凭记忆在心里查表。

### 产品方向脑暴 (What to Build)
一个"边聊边标"的双栏对话窗口：
- **左栏**：用户像微信聊天一样输入。
- **右栏**：每收到一条消息，AI 默默识别 HPO 候选词，实时打 Tag："已识别 HP:0000750 (发育迟缓) / HP:0002355 (频繁跌倒)，置信度 92%"。
- **底部**：一键生成"我的家族 HPO 词条云"。

### 黑客松 MVP 匹配度
**极高**。核心是写一个极好的 Router + System Prompt + Streamlit 双栏 UI + MCP 接 HPO API。路演 demo 路径：用户敲一句话 → 几秒内右栏出现标准 HPO 编码，技术张力拉满。

### MCP 和 RAG 必要性评估
- **MCP：极高**。HPO 库有 17,000+ 词条且持续更新，必须实时调用 `hpo.jax.org/api/hpo/term/` 做精确映射，本地爬取不现实。
- **RAG：高**。HPO 词条存在大量同义词、层级关系（如"频繁跌倒"是"共济失调"的子表型），需用 RAG 提供语义上下文辅助 LLM 选词。

## 场景二：VUS 报告"急救翻译官"

### Problem Statement (痛点界定)
**目标用户**：画像 A——刚拿到孩子基因 Panel 报告、上面写着 `CYP2D6 意义未明变异` 的焦虑妈妈。
**核心摩擦**：VUS 在 ClinVar 中占比超 40%，但患者无从知晓其真实含义。当晚百度"基因突变"后被各种绝症信息淹没，情绪崩溃，急需一个"24 小时在线、不会吓她"的解释员。

### 为什么传统方案失效
- 丁香医生等科普文无法针对**她具体的那个基因**做解释。
- 通用 LLM 会为了"安抚"用户而编造"这一定是良性的"或"可能致癌"，极易引发合规事故。

### 产品方向脑暴 (What to Build)
一个"粘贴即解"的报告解读器：
- 用户粘贴报告中变异位点或上传图片 OCR。
- AI 立即调用 ClinVar 返回该位点的真实分类（Pathogenic / Likely Benign / VUS / Conflicting）。
- 根据分类用三层语言梯度解释（小学版 / 中学版 / 临床版），并强制附加 ACMG 分类标准说明。

### 黑客松 MVP 匹配度
**极高**。这是最容易被路演评委共情的故事：演示者掏出自己/朋友的真实 VUS 报告，现场解压。

### MCP 和 RAG 必要性评估
- **MCP：极高**。必须连接 ClinVar/EVA 实时查询位点分类、本地知识库 1 周就过时。
- **RAG：保命级（极高）**。必须强制引用 ACMG `ClinGen Variant Curation` 标准文档，杜绝 LLM 自创分类解释。

## 场景三：15 分钟门诊"彩排器"与《就诊备忘》生成器

### Problem Statement (痛点界定)
**目标用户**：画像 B——为孩子肌张力低下奔波 5 年的寻医父亲。
**核心摩擦**：他知道家族病史很多，但一进诊室面对白大褂就大脑空白、抓不住重点。15 分钟过去后，医生只问到了"大概症状"，关键阴性家族史（如"我妻子家没有人有类似症状"）完全没讲。

### 为什么传统方案失效
- 没有任何工具帮患者**预演**问诊流程。
- 医院提供的纸质问诊表是通用模板，无法映射到遗传咨询所需的家系结构。

### 产品方向脑暴 (What to Build)
- **模式 A：彩排对话**——AI 扮演医生反向提问："您爱人的家族里有人出现过类似症状吗？""孩子出生时有没有窒息史？"，把盲点全问出来。
- **模式 B：备忘生成**——根据对话，输出一份双视角 PDF：**上半页是给医生的结构化 HPO + 家系文字描述**；**下半页是给患者的免责与挂号建议**。

### 黑客松 MVP 匹配度
**极高**。PDF 生成可用 `reportlab`，30 分钟就能跑通。路演价值高：直接解决"医患沟通带宽不足"的根本痛点。

### MCP 和 RAG 必要性评估
- **MCP：高**。HPO 映射必需。
- **RAG：高**。需内嵌中华医学会遗传学分会的"门诊问诊模板"作为彩排问题库，确保覆盖度。

## 场景四：遗传概率的"概念科普"助手（非数字预测）

### Problem Statement (痛点界定)
**目标用户**：所有携带致病变异或家族史阳性的患者。
**核心摩擦**：患者焦虑追问"我孩子得病概率多少？"。医生要么敷衍回答"50%"（不准确），要么拒绝回答（患者更焦虑）。

### 为什么传统方案失效
- 静态科普文无法个性化（外显率受年龄、性别、生活方式影响）。
- 通用 LLM 会给出伪精确数字（如"73.2%"），严重违反 FDA SaMD 红线。

### 产品方向脑暴 (What to Build)
一个"概念拆解"模式：
- 用户问"概率"，AI **绝不输出数字**，而是拆解为三个变量讲解：
  1. 遗传模式（这个基因是显性还是隐性？——用"拼图"类比）
  2. 外显率（有这个突变 ≠ 一定发病——用"种子与土壤"类比）
  3. 表现度（同一家人的症状为何不同——用"同一首歌不同唱法"类比）
- 结尾强制 CTA："请携带您的基因报告挂号 XX 医院遗传咨询科，由医生结合您的家族史进行综合判断。"

### 黑客松 MVP 匹配度
**极高**。这个场景的护城河不是技术，是**提示词工程**——路演时可重点展示"无论你怎么追问，我都不会输出百分比"。

### MCP 和 RAG 必要性评估
- **MCP：低**。此场景不依赖外部动态数据。
- **RAG：保命级（极高）**。必须用 RAG 锁死输出：本地库里只有"概念解释 + 强制 CTA 话术"，并预设"如检测到输出数字则强制重写"。

## 场景五：三代家系图谱（Pedigree）口述生成器

### Problem Statement (痛点界定)
**目标用户**：所有需要做遗传咨询的家族代表。
**核心摩擦**：医生需要看三代家系图才能判断遗传模式，但让家属现场手绘三代图谱几乎不可能——大家族谁生谁死都记不清，更别说发病年龄、死因。

### 为什么传统方案失效
- 手绘家系图需要专业训练（如知道"箭头=流产"、"空心=未发病"等符号）。
- 现有家系图软件（如 Progeny）是英文且收费，家属不可能自己用。

### 产品方向脑暴 (What to Build)
- AI 通过对话引导用户"报家底"（谁还活着、谁得过什么病、多大发病）。
- 后台用 Graphviz 或 Mermaid 语法实时渲染家系图。
- 每个家族成员卡片点击后展示该成员关联的 HPO 词条。

### 黑客松 MVP 匹配度
**极高**。Mermaid 渲染只需 20 行代码，演示效果非常直观（一张图谱动态生长出来）。

### MCP 和 RAG 必要性评估
- **MCP：中**。HPO 映射需要，但家系关系抽取主要靠 LLM 本身。
- **RAG：中**。需引用家系图谱标准符号系统（如"完全填充=已发病、半填充=未知"）确保一致性。

## 场景六：基因/变异名"白话词典"

### Problem Statement (痛点界定)
**目标用户**：拿到全外显子测序报告、面对几十个陌生基因符号（`SCN1A`、`KCNQ2`、`MECP2`...）的患者。
**核心摩擦**：报告里密密麻麻的基因名根本无法阅读；搜索引擎结果质量参差不齐，且对非专业人士极不友好。

### 为什么传统方案失效
- Wikipedia 太学术；百度健康充满竞价排名。
- 一个一个基因查太慢，且查到的信息无法整合成"我的报告整体在说什么"。

### 产品方向脑暴 (What to Build)
- 粘贴报告或基因列表 → AI 自动按"严重性 + 关联疾病"分组。
- 每个基因卡片包含：通俗功能解释（"这个基因管的是神经细胞的'刹车'"）、关联疾病图谱、ACMG 证据等级。
- 顶部给出整体阅读引导："报告中 X 个为致病性、Y 个为 VUS、Z 个为良性，重点关注前 X 个。"

### 黑客松 MVP 匹配度
**极高**。这是最容易展示"专业感"的功能，配合 RAG 来源引用让评委立刻信任。

### MCP 和 RAG 必要性评估
- **MCP：极高**。必须连接 NCBI Gene / OMIM API 实时查询基因功能与疾病关联。
- **RAG：高**。需引用 OMIM 的 patient-facing 科普摘要（避免直读学术 entry），保证通俗性。

## 场景七：多症状首诊科室智能导航

### Problem Statement (痛点界定)
**目标用户**：症状分散、不知道该挂哪科的患者。
**核心摩擦**：罕见病常表现为多系统症状（同时有心脏、骨骼、皮肤问题），患者跑错科室 5+ 次是常态。

### 为什么传统方案失效
- 医院官网的挂号导航按单系统划分，无法处理组合症状。
- 通用 LLM 推荐"挂心内科"过于粗暴。

### 产品方向脑暴 (What to Build)
- 用户描述症状组合 → AI 先抽 HPO → 再用 HPO 关联到多组科室。
- 输出"推荐科室组合 + 推荐理由"，并**显式提示**"建议优先挂号【医学遗传科】做总协调，避免重复检查"。
- 附带"如果挂不到遗传科，挂哪两个替代科室"的降级方案。

### 黑客松 MVP 匹配度
**高**。科室映射库可静态内置，演示时贴近真实挂号场景，评委有强代入感。

### MCP 和 RAG 必要性评估
- **MCP：高**。HPO 关联需要实时查询。
- **RAG：高**。需引用各医院科室指南与中华医学会罕见病分会的"罕见病首诊推荐路径"作为权威背书。

## 场景八：基因检测前的"知情同意"对话助手

### Problem Statement (痛点界定)
**目标用户**：犹豫是否要做基因检测（如 Panel、WES）的健康人。
**核心摩擦**：基因检测一旦检出 VUS 或意外发现（Secondary Findings），可能引发严重心理冲击。检测前的"遗传咨询"在国内几乎不可及，导致患者盲签知情同意书。

### 为什么传统方案失效
- 医院提供的知情同意书是法律文件而非教育工具，患者根本读不懂。
- 检测公司只关心"卖产品"，不会详细告知"检出 VUS 怎么办"。

### 产品方向脑暴 (What to Build)
- 对话式预检评估：AI 反向提问 10 个关键问题（"如果检出与现有疾病无关的癌症易感基因，您希望知道吗？"）。
- 根据回答给出**决策辅助矩阵**：
  - "建议检测" / "暂缓" / "建议先做家族史评估"
- 强调"心理准备度"评估，附带心理咨询资源链接。

### 黑客松 MVP 匹配度
**中（伦理风险偏高，需谨慎）**。demo 时建议加免责声明"本工具不替代医师遗传咨询"，但作为产品方向极具差异化。

### MCP 和 RAG 必要性评估
- **MCP：中**。可调用 ACMG SF v3.0 意外发现清单。
- **RAG：极高**。必须严格引用 ACMG/NSGC 的"预检咨询指南"，确保每个问题都符合行业伦理框架。

## 场景九：确诊后的"亲属温和告知信"草拟器

### Problem Statement (痛点界定)
**目标用户**：刚确诊为 BRCA1/林奇综合征等家族遗传病先证者的患者。
**核心摩擦**：理论上所有一级亲属都应做"级联筛查（Cascade Screening）"，但患者不知如何开口——直说怕吓到亲戚、隐瞒又延误诊治。

### 为什么传统方案失效
- 没有现成的"告知信模板"工具。
- 通用 LLM 写出的信要么过于学术、要么过于煽情。

### 产品方向脑暴 (What to Build)
- 输入：疾病类型 + 目标亲属（父母/兄弟姐妹/堂亲）+ 亲密度（极熟/普通/疏远）。
- 输出：3 套不同温度的告知信草稿（"开门见山版"/"委婉铺垫版"/"医生背书版"），每套都附带"建议附上的官方科普链接二维码"。
- 强调"告知但不强迫"——明确告知权在亲属，但提供支持渠道。

### 黑客松 MVP 匹配度
**极高**。这是隐藏的情感杀手锏功能，路演时讲一个真实案例即可打动全场。

### MCP 和 RAG 必要性评估
- **MCP：中**。可调用 OMIM 拉取家族级联筛查指南。
- **RAG：高**。需引用 NSGC（美国遗传咨询师协会）的告知话术模板，确保专业与温度并存。

## 场景十：备孕/孕前遗传咨询伴侣

### Problem Statement (痛点界定)
**目标用户**：已有家族遗传病史或曾生育过患儿的备孕夫妇。
**核心摩擦**：他们想了解"这一胎的风险"，但产前遗传咨询门诊一号难求，且每次只能问 15 分钟。

### 为什么传统方案失效
- 教科书级的"孟德尔遗传"讲解无法与个人情境挂钩。
- 任何"概率数字"都涉及红线，AI 输出数字风险高。

### 产品方向脑暴 (What to Build)
- 双人协作模式：夫妻双方各自输入家族史 → AI 合并去重 → 识别隐性遗传重合风险。
- **不输出"孩子得病概率"**，而是给出"建议与遗传咨询师讨论的 3 个具体问题清单" + "备孕前可考虑的检测选项对比表"（如 PGT-M vs 产前诊断 vs 新生儿筛查）。
- 配套"丈夫怎么和妻子解释家族史"的话术建议（情感支持层）。

### 黑客松 MVP 匹配度
**高**。该场景用户决策周期长、付费意愿高，未来商业化想象空间大。

### MCP 和 RAG 必要性评估
- **MCP：高**。HPO/OMIM 查询必需，且需查询 ClinGen 的剂量敏感性数据。
- **RAG：保命级（极高）**。需引用 ACMG/ACOG 备孕指南，并预设"概率类问题 → 强制转为'建议咨询问题清单'"的回复模板。

## 全局提示：10 个场景如何收敛为 MVP

以上 10 个不是 10 个独立产品，而是**一套"伴诊智能体"的 10 个功能开关**。建议在 MVP 阶段聚焦**前三高优先级场景**：

| 优先级 | 场景 | 路演价值 | 技术亮点 |
|---|---|---|---|
| ⭐⭐⭐ | 场景一（白话→HPO） | 高 | MCP + Streamlit 双栏 |
| ⭐⭐⭐ | 场景二（VUS 急救翻译） | 极高 | ClinVar MCP + ACMG RAG |
| ⭐⭐⭐ | 场景三（门诊彩排） | 高 | PDF 生成 + 双视角输出 |
| ⭐⭐ | 场景四（概率科普） | 中 | 纯提示词工程、护栏演示 |
| ⭐⭐ | 场景五（家系图谱） | 高 | Mermaid 实时渲染 |
| 其余 | 场景六～十 | — | 后续迭代 |

**一句话总结**：MVP 的"杀手组合" = **场景一的实时 HPO 抽取（技术酷炫） + 场景二的 VUS 翻译（情绪共鸣） + 场景三的 PDF 输出（价值闭环）**，这三条主线跑通后，其余 7 个场景都可以作为"功能开关"在同一套架构上横向扩展。
