# 后端知识库架构与数据字典 (MCP & RAG)

## 1. 核心划界：MCP 是“翻译官”，RAG 是“教科书”

在医疗垂类应用中，这两个模块的分工必须极其明确，绝不能混淆：

* **MCP (Model Context Protocol) = 动态翻译官**
  它不存任何整段的文章，它只负责“查字典”。我们外接人类表型本体（HPO）数据库，是为了把家长说的“孩子整天傻笑”，通过 API 瞬间翻译成国际标准的 `HP:0000748` (不恰当的笑)。这一步的核心目的是**标准化输入**。

* **RAG (Retrieval-Augmented Generation) = 权威教科书**
  这里面存的是长篇的、严谨的医学文档切片。当系统拿到标准化的症状和基因报告时，它必须去 RAG 里“翻书”，看看书上是怎么规定的，然后严格照本宣科地输出给用户，这就是所谓的**“保命护栏”**。

## 2. RAG 里到底要存什么？(The "What" & The "Where")

我们的 RAG 知识库需要严格划分为以下三个“数据桶”，用于填充 RAG 本地向量知识库的结构化医学资料。这些内容提取自美国儿科学会 (AAP)、GeneReviews 罕见病数据库以及权威文献的最新共识。

> **操作指南：** 将以下文本切片（Chunking）后存入系统的本地向量数据库（如 ChromaDB）。

### 数据桶 A：鉴别诊断与临床指南 (系统比对规则池)

**1. 孤独症谱系障碍 (ASD) 基础标准与初级保健**
* **权威来源:** 美国儿科学会 (AAP) 临床指南
* **核心规则:** 在儿童 18 个月和 24 个月必须进行标准化筛查。核心表现为跨情境的社交沟通缺陷，以及局限、重复的行为模式。
* **预警机制:** 如果患儿伴发新发的攻击性或严重的自伤行为，干预的首要原则并非盲目使用精神药物，必须首先全面排除隐匿性躯体疼痛（如隐匿的牙痛或胃肠道痉挛）。
* **文献链接:** [AAP 临床指南](https://publications.aap.org/pediatrics/article/145/1/e20193447/36917/Identification-Evaluation-and-Management-of?autologincheck=redirected)

**2. 脆性 X 综合征 (Fragile X Syndrome, FXS)**
* **权威来源:** GeneReviews: FMR1-Related Disorders
* **鉴别特征:**
  * 最常见的导致 ASD 的单基因突变（FMR1 基因 CGG 异常扩增）。
  * 高达 50%-70% 的男性患者完全符合自闭症诊断（如社会回避、缺乏眼神交流、持续拍手）。
* **核心鉴别锚点:** 患者常伴有明显的颅面特征（长脸、突出前额、大耳廓），且超过 80% 会合并强烈的 ADHD 症状及难以控制的焦虑。
* **文献链接:** [GeneReviews - FMR1](https://www.ncbi.nlm.nih.gov/books/NBK1384/)

**3. 安格曼综合征 (Angelman Syndrome)**
* **权威来源:** GeneReviews: Angelman Syndrome
* **鉴别特征:**
  * 由 15q11.2-q13 区域母源 UBE3A 基因表达缺失引起。
  * 临床重合: 言语功能严重剥夺（几乎无语言）、刻板行为、重度智力障碍。
* **核心鉴别锚点:** 标志性的“快乐木偶”行为（频繁爆发、极易被激惹的大笑和微笑）；明显的步态共济失调（宽基底、手臂高举屈曲）；极高发的癫痫以及严重睡眠节律紊乱。
* **文献链接:** [GeneReviews - Angelman](https://www.ncbi.nlm.nih.gov/books/NBK1144/)

**4. 结节性硬化症 (Tuberous Sclerosis Complex, TSC)**
* **权威来源:** GeneReviews: Tuberous Sclerosis Complex
* **鉴别特征:**
  * TSC1/TSC2 基因突变导致。
* **核心鉴别锚点:** 皮肤提供至关重要的线索，包括 3 片以上的叶状色素减退斑（白蜡树叶斑）、面部血管纤维瘤。神经系统中由于皮质结节的存在，常表现为婴儿痉挛症或难治性癫痫，这些常被误认为是退化型 ASD。
* **文献链接:** [GeneReviews - TSC](https://www.ncbi.nlm.nih.gov/books/NBK1220/)

**5. 其他伴有 ASD 表型的重要过度生长/代谢综合征**
* **Sotos 综合征:** [GeneReviews: Sotos Syndrome](https://www.ncbi.nlm.nih.gov/books/NBK1479/)。表现为过度生长（儿童期身高常超 98 百分位）、巨头畸形、骨龄提前，常因缺乏社交感知被误诊为原发性 ASD。
* **Prader-Willi 综合征 (小胖威利):** [GeneReviews: Prader-Willi Syndrome](https://www.ncbi.nlm.nih.gov/books/NBK1330/)。由 15q11.2-q13 父源片段缺失引起。婴儿期存在极度肌张力低下和喂养困难，但在儿童期后会爆发无可遏制的暴食症及极度固执、强迫的行为模式。

### 数据桶 B：基因测序与 VUS 科学解读 (患者教育与降维安抚)

**1. 全外显子组测序 (WES) 的核心价值**
* **权威来源:** 比较基因组学研究 (PMID: 33921431)
* **科普安抚话术:** 在伴有复杂躯体症状或癫痫的 ASD 患者中，全外显子测序 (WES) 是目前极其重要的确诊工具（诊断率可达 20%-30%）。进行测序的核心目的不是为了判定“绝症”，而是为了精确解释发病机制，并据此制定积极的针对性监控方案（例如为高危变异提前规划抗癫痫策略）。
* **文献链接:** [PubMed 33921431](https://pubmed.ncbi.nlm.nih.gov/33921431/)

**2. 怎样科学看待“临床意义未明变异” (VUS)**
* **权威来源:** ACMG 大规模变异数据分析 (PMID: 37878314)
* **科普安抚话术:**
  * **VUS 极其常见：** 在进行广泛基因组检测的人群中，高达 41% 的个体都会收到至少一个 VUS 报告，这是科学技术发展过程中的正常现象。
  * **绝不是确诊书：** 报告上的 VUS 就像是一本庞大说明书中暂时无法查阅字典的“生僻字”。它只代表当前的医学数据库还不足以判断它的明确意义。
  * **不要过度恐慌：** 科学实证数据显示，历经平均近三年的重分类过程后，高达 80.2% 的 VUS 最终会被证实为完全无害的“良性改变”。因此，国际指南严禁临床医生仅仅依据一个 VUS 就对孩子做出激进的医疗干预决策。
* **文献链接:** [PubMed 37878314](https://pubmed.ncbi.nlm.nih.gov/37878314/)

### 数据桶 C：合规护栏与免责声明 (强制收口机制)

**Non-Device CDS 豁免提示条款（注：必须在每份报告末尾强制展示）**
> “本系统提供的信息比对与基因知识科普均基于权威医学文献检索生成。本报告仅用于帮助家长梳理日常生活中的前置症状线索，并翻译晦涩的基因术语。本系统不可替代执业医师的面诊，绝不作为任何疾病的确诊结论，亦不提供任何具体的干预或用药建议。强烈建议您携带此信息整理单，前往正规三甲医疗机构的儿童发育行为科及医学遗传科，由专业医生进行最终临床评估。”

有了这份数据支撑，当大模型遇到携带晦涩基因报告的焦虑用户，或者发现用户的描述命中特定鉴别锚点时，就能安全、专业地提供前置排查建议，并在最后通过严格的免责条款兜底。

## 3. 后台运作的逻辑闭环

理清了核心数据来源，后台的运作逻辑呈现为一个极度线性的闭环。这也是能让 MVP 稳定跑通的架构设计：

1. **信息输入:** 用户输入白话文症状和 `MECP2 VUS` 等基因报告。
2. **术语翻译 (MCP):** MCP 启动，将白话文翻译为标准的 HPO 术语（如转化为 `语言发育倒退`）。
3. **特征比对 (RAG - 桶 A):** 系统拿着 `语言发育倒退` 和 `MECP2 VUS`，去检索 RAG 的数据桶 A (GeneReviews)，发现高度匹配 Rett 综合征的预警特征。
4. **科普安抚 (RAG - 桶 B):** 系统去检索 RAG 的数据桶 B (ACMG 科普)，提取关于 VUS 的标准降维安抚话术。
5. **合规收口 (RAG - 桶 C):** 系统综合这些“书本上的事实”，结合数据桶 C 的合规约束，生成一份严谨、温和、带有具体就诊建议的最终报告。
